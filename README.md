# C++ Programming Assignment 1

A collection of standalone C++ programs covering fundamental programming concepts such as input/output, arithmetic operations, conditional statements, loops, taxation, population projection, and geometry.

## Overview

This project contains three individual C++ programs designed to solve practical problems and demonstrate core C++ programming skills:

* Triangle Area Calculator
* Tax Calculation Program
* Population Projection

Each program is independent and can be compiled and executed separately.

## Project Structure

```text
Cpp_assignment_1_Individual/
├── Triangle_area.cpp
├── Taxation.cpp
├── Population.cpp
└── README.md
```

## Programs Included

### 1. Triangle Area Calculator

**File:** `Triangle_area.cpp`

Calculates the area of a triangle from the coordinates of its three vertices using the distance formula and Heron's formula.

### 2. Taxation Program

**File:** `Taxation.cpp`

Calculates tax based on residence status and taxable income using different income-tax brackets for residents and non-residents.

### 3. Population Projection

**File:** `Population.cpp`

Projects the population for the next five years using estimated annual birth, death, and immigration rates.

## How to Compile and Run

Use a C++ compiler such as `g++`.

```bash
g++ Triangle_area.cpp -o Triangle_area
./Triangle_area
```

For other programs, replace the filename accordingly:

```bash
g++ Taxation.cpp -o Taxation
./Taxation
```

```bash
g++ Population.cpp -o Population
./Population
```
